# বাজার দর (BazarDor) - নিত্যপ্রয়োজনীয় পণ্যের বাজারদর ট্র্যাকার

নিত্যপ্রয়োজনীয় পণ্যের (চাল, তেল, ডিম, মাছ, মাংস, সবজি) বাজারদর দেখানোর একটি Next.js ওয়েব অ্যাপ।

## ব্যবহৃত প্রযুক্তি
- Next.js 14 (App Router), TypeScript
- Tailwind CSS
- react-hot-toast
- অথেনটিকেশন: ডেমো ব্যবস্থা (React Context + localStorage)। বাস্তব BetterAuth সংযোগ পরে যোগ করার জন্য `src/context/AuthContext.tsx` ফাইলটি একমাত্র পরিবর্তনের জায়গা।

## প্রধান ৫টি বৈশিষ্ট্য
1. **বাংলা তারিখ ও প্রাইস টিকার:** সংশোধিত বাংলা পঞ্জিকা অনুযায়ী আজকের তারিখ এবং স্ক্রোলিং দামের স্ট্রিপ।
2. **দাম বাড়া ও কমার সেকশন:** "আজ দাম বেড়েছে ▲" এবং "আজ দাম কমেছে ▼"।
3. **সাংখ্যিক সর্টিং ও সার্চ:** "কম থেকে বেশি" ও "বেশি থেকে কম" দাম অনুযায়ী সাজানো।
4. **সুরক্ষিত পণ্য বিবরণ:** সাইন ইন ছাড়া `/product/[slug]` দেখা যায় না; বাজারভিত্তিক দর, সর্বনিম্ন, গড় ও সর্বোচ্চ দাম।
5. **প্রোফাইল আপডেট:** `/profile/update` থেকে নাম পরিবর্তন।

## চালানোর নিয়ম
```bash
npm install
npm run dev
```
ব্রাউজারে খুলুন: http://localhost:3000
